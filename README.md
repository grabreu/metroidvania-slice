# metroidvania-slice

2D metroidvania vertical slice in the style of Hollow Knight, built in Unity. Prototype / game-jam style project; games are a side outlet, not a portfolio centerpiece.

**Status:** draft. Nothing is implemented yet.

## Tech stack

Unity 6000.6.7f1 (Universal 2D, URP) · C# (core systems) · PlayMaker (visual FSMs for enemy, boss, and game-state behavior)

## Scope

Vertical slice, not a full game:

- One area.
- Complete movement.
- One or two enemies.
- One boss.
